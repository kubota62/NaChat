# 社員向け：チャットの使い方

対象：自分のPCのブラウザでNaChatを使う方。Dockerやサーバー操作は不要です。

## ログイン

管理者から接続URL、メールアドレス、初期パスワードを受け取り、社内ネットワークからURLを開きます。初回は現在の初期パスワードと12文字以上の新しいパスワードを入力してください。簡単すぎるパスワードなどは使えない場合があります。

パスワードを忘れた場合はアカウント管理者へ再設定を依頼します。自動の再設定メールはありません。

## 画面の見方

| 場所 | できること |
|---|---|
| 左の一覧 | チャンネルやDMを選択。数字は未読件数 |
| 中央 | メッセージを読む・書く |
| 右のスレッド | 特定の投稿への返信を読む・書く |
| 上部の検索欄 | 閲覧できる会話のメッセージを検索 |
| 左下の設定 | 自分のパスワード変更、ログアウト |

## 投稿と返信

1. 会話を選び、下の入力欄にメッセージを書きます。
2. 送信ボタン、または **Ctrl + Enter** で送信します。MacではCommand + Enterも使えます。
3. Enterで改行できます。日本語変換の確定だけでは送信されません。

特定の投稿への返答は、投稿にマウスを合わせて「スレッドで返信」を選び、右側の入力欄に書きます。「○件の返信」からもスレッドを開けます。

自分の投稿は「編集」「削除」で変更できます。他人の投稿は変更できません。「いいね」で👍が付き、もう一度押すと取り消せます。

## 個別に相談する（DM）

左の「ダイレクトメッセージ」の追加ボタン、または「メンバーに話しかける」から相手を選びます。同じ相手は同じ会話が開きます。現在は1対1のみです。

## 相手に呼びかける（メンション）

入力欄の「@」から相手を選ぶと、メールアドレス形式のメンションが入ります。「自分へのメンション」は自分への言及を検索する一覧です。OS通知や通知メールは送信されません。

## ファイルを添付する

クリップボタンでファイルを選び、送信します。**1投稿につき最大5個、合計25MBまで**です。ファイル名を押すとダウンロードできます。

対応画像にはプレビューが表示されます。HTMLやSVGなどはダウンロードとして扱います。会話を閲覧できない人は添付も取得できません。

## 検索と過去の履歴

上部の検索欄にキーワードを入力してEnterを押します。閲覧できる会話のみが対象で、結果は最大50件です。結果が多いときは具体的な言葉に変えてください。

会話・返信は50件ずつ表示します。「以前のメッセージを表示」「以前の返信を表示」でさかのぼれます。現在、長いスレッドでは新着の同期により直近の返信表示へ戻ることがあります。

## 未読と接続状態

スレッドの返信も未読件数に含まれます。チャンネルを開くだけでは返信は既読にならないため、該当スレッドを開いてください。

切断時は自動再接続します。「再接続しています…」が続く場合は社内ネットワークを確認してください。送信エラー時は履歴を確認し、入力欄に残った投稿を再送できます。

## チャンネルの管理

「会話をはじめる」またはチャンネル追加ボタンから、名前・説明・公開範囲を設定します。

| 種類 | 閲覧できる人 |
|---|---|
| 公開 | 社内の有効なアカウントを持つ全員 |
| 非公開 | 追加されたメンバーのみ |

**チャンネル作成者**は会話右上のメンバーボタンで追加・削除を行えます。非公開に追加された人は過去の履歴も閲覧できます。削除された人は以後アクセスできません。

公開チャンネルでは、メンバーから削除しても閲覧を制限できません。限定したい会話は最初から非公開で作成してください。現在、チャンネルの改名・削除・公開範囲切り替え・所有者変更の画面はありません。

## 困ったとき

| 状況 | 問い合わせ・対応 |
|---|---|
| 画面が開かない・URLが不明 | 社内ネットワークを確認し、サーバー担当者へ |
| ログインできない・PWを忘れた | アカウント管理者へ |
| 非公開チャンネルが見えない | チャンネル作成者へ追加を依頼 |
| 未読が残る | スレッドの返信を確認 |
| 添付できない | 個数・合計容量を確認 |

アカウント管理者にも、他人同士のDMや未参加の非公開会話を自由に閲覧する画面権限はありません。ただしDBを直接管理するサーバー運用者は別です。投稿を削除してもバックアップから直ちに消えるわけではありません。
