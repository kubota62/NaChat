# アカウント管理者向け

対象：社員アカウントをブラウザで管理する担当者。設置・バックアップは[サーバー担当者](SERVER_GUIDE.md)が行います。

## 担当分担

サーバー担当者が最初の管理者を作成し、URLと初期ログイン情報を渡します。管理者はログイン後、社員ごとのアカウントを作成します。管理者アカウントを複数人で共有しないでください。

## 社員のアカウントを作成

1. 左下の「設定」→「ユーザー管理」を開きます。
2. 表示名、メールアドレス、8文字以上の初期パスワードを入力します。
3. 「ユーザーを追加」を押します。
4. 接続URL・メールアドレス・初期パスワードを本人へ個別に案内します。
5. [社員向けガイド](USER_GUIDE.md)を渡します。

通知メールは自動送信されません。社員の初回パスワード変更は任意です。この画面では一般社員用アカウントを作成します。管理者の追加はサーバー担当者へ依頼してください。

## パスワードを再設定

「ユーザー管理」で対象者の「再設定」を押し、新しい初期パスワードを設定します。本人へ伝えて再ログインを案内してください。以前のログイン状態は失効します。

最上位管理者の変更はこの管理画面ではできません。自分がログインできる場合は「アカウント」で変更し、忘れた場合はサーバー担当者へ復旧を依頼します。

## 退職・利用停止

対象者の「無効化」を押すと利用できなくなります。過去の投稿は残ります。再開時は「有効化」を選びます。

チャンネル作成者を無効化する場合は継続管理について保守担当者と相談してください。所有者変更の画面はまだありません。

## チャンネル管理との違い

- アカウント管理者：ユーザーの作成・再設定・無効化。
- チャンネル作成者：自分が作成したチャンネルのメンバー管理。
- 管理者でも未参加の非公開会話や他人同士のDMは閲覧できません。

## 利用開始前に社員へ案内する内容

- 接続URLと、社内ネットワーク接続が必要なこと。
- アカウント・パスワードの問い合わせ先。
- チャンネルの用途と、公開・非公開の使い分け。
- メンションはOS通知やメールを送らないこと。
- 社内のデータ保存・利用ルール。

社員にDockerの操作を案内する必要はありません。
