# NaChat 利用ガイド

NaChatは、社内ネットワークで使うチャットツールです。部署やプロジェクトごとの会話、個別の相談、ファイル共有に使えます。

社員はブラウザから利用します。アプリのインストールは不要です。サーバー担当者がホストPCにNaChatを設置し、接続URLを案内します。

## 自分の役割に合った手順を読む

| 役割 | 行うこと | 読むガイド |
|---|---|---|
| 社員（クライアント側） | ログイン、投稿、DM、返信、添付、検索 | [社員向け](docs/USER_GUIDE.md) |
| チャンネル作成者（クライアント側） | チャンネル作成、非公開メンバーの管理 | [チャンネルの管理](docs/USER_GUIDE.md#チャンネルの管理) |
| アカウント管理者（ブラウザで操作） | 社員のアカウント発行、再設定、無効化 | [アカウント管理者向け](docs/ADMIN_GUIDE.md) |
| サーバー担当者（サーバー側） | 設置、起動、社内公開、バックアップ、更新、障害対応 | [サーバー担当者向け](docs/SERVER_GUIDE.md) |
| 開発・保守担当者 | ソース変更、ビルド、テスト、配布物の作成 | [開発・保守担当者向け](docs/DEVELOPMENT.md) |

一人が複数の役割を兼ねても構いません。アカウント管理者の通常業務はブラウザで完結します。

## 社員が使い始めるには

1. 管理者から **接続URL・メールアドレス・初期パスワード** を受け取ります。
2. 社内ネットワークに接続し、ブラウザでURLを開きます。
3. 初回ログインでは、12文字以上の新しいパスワードに変更します。
4. 左のチャンネルを選ぶか、DMを開始します。

URLが分からない場合はサーバー担当者へ、アカウントがない場合はアカウント管理者へお問い合わせください。

**別PCから利用するときに localhost は指定しません。** localhostは操作しているPC自身を指します。管理者が案内した社内URLを使用してください。

## 社内のWindows PCへ持ち込む場合

[Windows社内テスト手順.txt](Windows社内テスト手順.txt)を参照してください。Docker DesktopはLinuxコンテナで使用します。ホスト単体での試用と、証明書が必要な別PCからのHTTPS接続を分けて説明しています。

## この開発PCで試す場合

起動・停止のコマンドは、[Docker起動手順.txt](Docker起動手順.txt)にまとめています。社内の別PCから利用するためのHTTPS設定と、Linuxへの持ち込み手順も記載しています。

Docker DesktopとNaChatが起動していれば、[http://localhost:8080](http://localhost:8080/) で試せます。初回管理者の情報はこのPCの「.local/初回ログイン.txt」にあります。初期パスワードは変更後に使えなくなります。

この管理者アカウントを社員へ共有せず、社員用アカウントを発行してください。標準設定ではこのPCからのみ接続できます。別PCから使う場合は[サーバー担当者向けガイド](docs/SERVER_GUIDE.md)の設定が必要です。

## 現在使える機能

- 公開・非公開チャンネル、1対1のDM
- 投稿、編集・削除、スレッド返信、いいね、未読表示
- メンション、ファイル添付、画像プレビュー、検索
- アカウント発行・無効化・パスワード再設定

現在は初期版です。通話、画面共有、OS通知、在席・入力中表示、SVNの自動通知は未実装です。ブラウザを閉じている間の通知もありません。

実施済みの確認と残課題は[検証状況](VALIDATION.md)、技術構成と設計の経緯は[設計書](ARCHITECTURE.md)・[設計レビュー](DESIGN_REVIEW.md)を参照してください。
